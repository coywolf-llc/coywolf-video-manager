# Coywolf Video Manager

> [!IMPORTANT]
> Coywolf Video Manager is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). The plugin is closed in the WordPress.org Plugin Directory. This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Video Manager is now the [Videos](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/videos.md) module in Coywolf Pack: a Cloudflare Stream library, a video block with a light embed, video schema and a video sitemap, and plays and likes.

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Managed, embedded and uploaded Cloudflare Stream videos from the WordPress admin, with a video block, plays and likes, video schema, captions and a video sitemap.

## If you still use it

The last release, [v1.0.63](https://github.com/coywolf-llc/coywolf-video-manager/releases/tag/v1.0.63), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
